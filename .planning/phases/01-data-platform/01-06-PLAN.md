<objective>
Ship the concrete `CoinglassClient` (httpx-backed, single AsyncClient per process per D-50) plus per-endpoint fetcher modules for funding-aggregate, open-interest history, liquidation history, and long/short ratio — every write attributed `source='coinglass_aggregate'` and idempotent via `copy_into_hypertable` from plan 01-01. Pydantic v2 strict schemas decode wire format; 4xx-non-429 routes to `dead_letter` (no retry); 5xx/429/transport errors raise so tenacity can retry under the bounded `coinglass_retry` policy.

Purpose: Coinglass is the multi-exchange aggregate that the Phase 2 features cross-reference against MEXC-native funding/OI to detect divergence (Pitfall 16). Every Coinglass row carries explicit `source='coinglass_aggregate'` so feature engineering NEVER conflates aggregates with native. The Hobbyist 30 req/min quota is the binding constraint — `aiolimiter` at 28/60 + tenacity exponential jitter keeps us under it deterministically.
Output: 6 new source files under `src/shortfire/ingest/coinglass/` + 4 test files + extended `tests/fakes/coinglass.py`.

    **Step 2: Create `src/shortfire/ingest/coinglass/schemas.py`** per RESEARCH.md §3 + PATTERNS.md Group 3.

    Module docstring: "Coinglass v4 response schemas. D-52 Pydantic v2 strict; Pitfall G `extra='allow'` to tolerate Coinglass renaming fields without breaking ingest; D-59 source attribution always 'coinglass_aggregate' (or 'coinglass_mexc_only' in Phase 2 EDA decision)."

    Define four BaseModel response schemas:
    - `class FundingRateListResponse(BaseModel)`: `model_config = ConfigDict(frozen=True, strict=True, extra='allow')`. Fields: `code: int, msg: str, data: tuple[FundingRateListRow, ...]`. The nested `FundingRateListRow` has `symbol: str` (Coinglass uses `"BTC"` not the ccxt unified format — see RESEARCH.md §1 "coinglass_symbol" mapping), `funding_rate: Decimal | None = None`, `next_funding_time: int | None = None`, plus a method `to_record(self, source: str = 'coinglass_aggregate') -> tuple` building the 6-tuple `(symbol_unified, ts_now_utc, funding_rate, source, 'ok')` for `raw_coinglass_funding_agg`. CRITICAL: the symbol field arriving from Coinglass is the bare coin (`"BTC"`); the caller in `funding_agg.py` is responsible for mapping it to the ccxt unified `BTC/USDT:USDT` via the `symbols.coinglass_symbol` lookup table from plan 01-04. The schema stores the wire value; the caller maps before INSERT.

    - `class OpenInterestHistoryResponse(BaseModel)`: `data: tuple[OpenInterestHistoryRow, ...]` with `OpenInterestHistoryRow` fields `time: int, open_interest_usd: Decimal | None = None`; method `to_records(self, symbol_unified: str, source: str = 'coinglass_aggregate') -> list[tuple]` returning a list of `(symbol_unified, datetime.fromtimestamp(time/1000, tz=timezone.utc), open_interest_usd, source, 'ok')` tuples for `raw_coinglass_oi`.

    - `class LiquidationCoinHistoryResponse(BaseModel)`: `data: tuple[LiquidationCoinHistoryRow, ...]` with `time: int, liquidation_long_usd: Decimal | None, liquidation_short_usd: Decimal | None`; method `to_records(...)` returning TWO record tuples per data row (one with side='long', one with side='short') for `raw_coinglass_liq`.

    - `class LongShortAccountRatioResponse(BaseModel)`: `data: tuple[LongShortAccountRatioRow, ...]` with `time: int, long_short_ratio: Decimal | None`; method `to_records(...)` returning rows for `raw_coinglass_lsr`.

    Note on `extra='allow'`: Phase 1 accepts schema drift gracefully. If Coinglass adds new fields, they pass through without breaking ingest. If a REQUIRED field is renamed (low frequency), Pydantic raises ValidationError on the renamed field and the row lands in `dead_letter` — which is the correct failure mode per D-52.

    ```
    import httpx
    import structlog
    from pydantic import ValidationError
    from shortfire.ingest.retry import coinglass_retry
    from shortfire.ingest.rate_limit import COINGLASS_LIMITER
    from shortfire.ingest.dead_letter.writer import write_to_dead_letter
    from shortfire.ingest.coinglass.schemas import (
        FundingRateListResponse, OpenInterestHistoryResponse,
        LiquidationCoinHistoryResponse, LongShortAccountRatioResponse,
    )
    from shortfire.settings.data_platform import DataPlatformSettings

    log = structlog.get_logger("ingest.coinglass.client")

    _COINGLASS_BASE = "https://open-api-v4.coinglass.com"


    class CoinglassClient:
        """Concrete Coinglass v4 client. D-50 single httpx.AsyncClient/process; D-51 limiter; D-72 retry."""

        def __init__(self, settings: DataPlatformSettings) -> None:
            if settings.coinglass is None:
                raise RuntimeError("DataPlatformSettings.coinglass must be configured for ingest")
            self._api_key = settings.coinglass.api_key.get_secret_value()
            self._client = httpx.AsyncClient(
                http2=True,
                timeout=10.0,
                limits=httpx.Limits(max_connections=20, max_keepalive_connections=10),
                headers={"CG-API-KEY": self._api_key, "accept": "application/json"},
            )

        async def _call(self, endpoint: str, params: dict | None = None) -> dict | None:
            """Internal: rate-limited GET with dead_letter on 4xx-non-429 and ValidationError."""
            url = f"{_COINGLASS_BASE}{endpoint}"
            async with COINGLASS_LIMITER:
                r = await self._client.get(url, params=params)
            if r.status_code in (429, 500, 502, 503, 504):
                r.raise_for_status()
            if r.status_code >= 400:
                # Permanent — route to dead_letter, do NOT raise (tenacity would retry)
                await write_to_dead_letter("coinglass_aggregate", endpoint, params.get("symbol") if params else None,
                                           r.text[:8000], "HTTPStatusError", f"HTTP {r.status_code}")
                return None
            return r.json()

        @coinglass_retry
        async def fetch_funding_rate_list(self) -> FundingRateListResponse | None:
            payload = await self._call("/api/futures/funding-rate-list")
            if payload is None:
                return None
            try:
                return FundingRateListResponse.model_validate(payload)
            except ValidationError as exc:
                await write_to_dead_letter("coinglass_aggregate", "/api/futures/funding-rate-list",
                                           None, str(payload)[:8000], "ValidationError", str(exc)[:2000])
                return None

        @coinglass_retry
        async def fetch_open_interest_history(self, symbol: str, interval: str = "1h") -> OpenInterestHistoryResponse | None:
            payload = await self._call("/api/futures/open-interest/history", params={"symbol": symbol, "interval": interval})
            if payload is None:
                return None
            try:
                return OpenInterestHistoryResponse.model_validate(payload)
            except ValidationError as exc:
                await write_to_dead_letter("coinglass_aggregate", "/api/futures/open-interest/history",
                                           symbol, str(payload)[:8000], "ValidationError", str(exc)[:2000])
                return None

        @coinglass_retry
        async def fetch_liquidation_coin_history(self, symbol: str, interval: str = "1h") -> LiquidationCoinHistoryResponse | None:
            payload = await self._call("/api/futures/liquidation/coin-history", params={"symbol": symbol, "interval": interval})
            if payload is None:
                return None
            try:
                return LiquidationCoinHistoryResponse.model_validate(payload)
            except ValidationError as exc:
                await write_to_dead_letter("coinglass_aggregate", "/api/futures/liquidation/coin-history",
                                           symbol, str(payload)[:8000], "ValidationError", str(exc)[:2000])
                return None

        @coinglass_retry
        async def fetch_long_short_account_ratio(self, symbol: str, interval: str = "1h") -> LongShortAccountRatioResponse | None:
            payload = await self._call("/api/futures/long-short-account-ratio", params={"symbol": symbol, "interval": interval})
            if payload is None:
                return None
            try:
                return LongShortAccountRatioResponse.model_validate(payload)
            except ValidationError as exc:
                await write_to_dead_letter("coinglass_aggregate", "/api/futures/long-short-account-ratio",
                                           symbol, str(payload)[:8000], "ValidationError", str(exc)[:2000])
                return None

        async def close(self) -> None:
            await self._client.aclose()
    ```

    ```
    from datetime import datetime, timezone
    import structlog
    from sqlalchemy.ext.asyncio import AsyncEngine

    from shortfire.ingest.storage.copy import copy_into_hypertable
    from shortfire.ingest.coinglass.client import CoinglassClient

    log = structlog.get_logger("ingest.coinglass.funding_agg")


    async def fetch_and_write(
        engine: AsyncEngine,
        client: CoinglassClient,
        coinglass_to_unified: dict[str, str],
    ) -> int:
        """Batch funding-rate-list endpoint (D-53: every 5 min, one call covers all symbols).

        Args:
            engine: AsyncEngine — write target.
            client: CoinglassClient — read source.
            coinglass_to_unified: e.g. {"BTC": "BTC/USDT:USDT", "ETH": "ETH/USDT:USDT"} —
                                  built from the `symbols` lookup table (plan 01-04).
                                  Coinglass returns bare-coin symbols; storage uses unified.

        Returns:
            Rows written.
        """
        resp = await client.fetch_funding_rate_list()
        if resp is None:
            log.warning("funding_agg.skipped", reason="fetch returned None — dead_letter already logged")
            return 0
        ts_now = datetime.now(timezone.utc)
        records = []
        for row in resp.data:
            unified = coinglass_to_unified.get(row.symbol)
            if unified is None:
                # Coinglass returned a symbol we don't have in symbols.coinglass_symbol → skip
                log.warning("funding_agg.unmapped_symbol", coinglass_symbol=row.symbol)
                continue
            if row.funding_rate is None:
                continue
            records.append((unified, ts_now, row.funding_rate, "coinglass_aggregate", "ok"))
        n = await copy_into_hypertable(
            engine,
            "raw_coinglass_funding_agg",
            records,
            columns=("symbol", "ts", "funding_rate", "source", "quality_flag"),
            conflict_columns=("symbol", "ts", "source"),
        )
        log.info("funding_agg.completed", rows_written=n)
        return n
    ```
